# 0007. Раздельные ошибки пустых полей и чекбокс «Запомнить меня»

Дата: 2026-11-06
Статус: принято

## Context

Форма логина на любую неудачу показывала одно сообщение «Неверное
имя пользователя или пароль», в том числе при пустых полях — пользователь
не понимал, что именно не так. Домашнее задание (`docs/homework.md`)
требует различать пустой логин, пустой пароль и оба пустых поля,
а также добавить чекбокс «Запомнить меня». Рассматривали HTML-атрибут
`required`: браузер заблокировал бы отправку и `#message` не появился бы —
ошибку нельзя было бы проверить Selenide-тестом единообразно с остальными.

## Decision

Валидация живёт в обработчике submit в `index.html`, без `required`:

- оба поля пустые → «Введите имя пользователя и пароль»;
- пустой логин → «Введите имя пользователя»;
- пустой пароль → «Введите пароль»;
- иначе проверка пары, при неверной — прежнее «Неверное имя
  пользователя или пароль».

Во всех ошибках `#message` получает класс `error`, успех не показывается.
Чекбокс `#remember` с подписью «Запомнить меня» добавлен между паролем
и кнопкой; пока это только UI, состояние нигде не сохраняется.

Тесты: `LoginNegativeTest` (неверная пара — параметризованный, три
пустых случая — три отдельных теста) и `rememberMeCheckboxIsClickable`
в `LoginTest`.

## Consequences

Проще: каждая ошибка проверяется по точному тексту и классу `error`.
Плата: тексты сообщений — контракт между `index.html` и тестами,
меняя одно, правь другое (`.devin/rules/index-html.md`). Тесты бегут
по версии на GitHub Pages (ADR-0006): до мержа в `main` новые тесты
красные. «Запомнить меня» пока ничего не запоминает — реальная
персистентность потребует отдельного решения.
